# 六模式与规则

| ID | 模式 | 逻辑 |
| --- | --- | --- |
| 0 | 自由计圈 | 启用飞手独占接收槽；ENTER建立/完成圈，EXIT重武装，按最短圈时滤重，最近200圈 |
| 1 | 驻留占领 | 单队驻留积累，同队多人不加速；双方争夺冻结，无人回退；占领后按归属时间计分 |
| 2 | 快速团队夺旗 | 单队有效在场立即换主；双方在场不切换，归属时间计分 |
| 3 | 单人守点 | 只启用一人；首次在场开始，离开扣生命、返回补充，归零失败；到时且已开始/未失败成功 |
| 4 | 个人混战 | 唯一在场飞手占领，可被其他人重夺；多人同时在场不偏向低索引，按个人归属时间计分 |
| 5 | 首次占领锁定 | 首次唯一在场飞手锁定归属，后续不能重夺 |

状态0待机、1运行、2暂停、3结束。最多8飞手，team1红/2蓝、slot0..3。频道按实际MHz去重（不同band可同频）。名称1–12字节合法UTF-8，RGB24位；完整传输布局见BLE文档。

草稿与本场冻结配置分开；运行/暂停不能改变比赛规则。开始清上一场，暂停不计暂停间隔，恢复需预检，停止结算并保存结果。故障后不自动继续。观测无效/超时、节点或会话变化、事件缺口会按规则暂停。

当前非计圈玩法依次观测飞手频道，不代表所有频道在同一时刻采样。增益/门限、校准按接收器维护；比赛同步不覆盖所有旗点RF参数。多C3汇总同场团队/个人成绩，缺失成员显式标记；不将不同场次或模式混加。跨门圈赛、携旗返回基地和未定义的全局赛制不在本版范围。

权威实现：`game.c`/`game.h`、`lap_timer.c`、`match.c`、`result_record.c`及`network.c`。
