# C3 ESP-NOW主从协议

## 拓扑与配置

role0独立、1固定主机、2成员。主机启用BLE和ESP-NOW，最多8成员；成员只启用ESP-NOW。相同非零network ID、同一16字节非零密钥、2.4GHz信道1..13；成员指定主机STA MAC。不自动主机选举。通过BLE14..17或串口net配置，保存重启生效；真实密钥不进入仓库。

## 线帧

packed `packet_t`共63字节，little-endian：version u8@0=1，type u8@1，network u32@2，boot u32@6，seq u32@10，length u8@14，data[32]@15，tag[16]@47。长度为有效data长度，剩余data填0。tag是对前47字节作HMAC-SHA256取前16字节，常量时间逐字节累计差异核对。所有节点同密钥属于同一信任域；认证不提供载荷加密。

| type | 用途 |
| --- | --- |
| 1 / 4 | 成员24字节心跳 / 主机心跳与取消边界 |
| 2 / 3 | 命令及目标boot / 应用结果ACK |
| 5 / 6 / 17 | 四时间戳探测/应答 / 事件时钟映射报告 |
| 7 / 8 / 9 | 飞手成绩21字节 / RF配置8字节 / 时钟与开场状态12字节 |
| 10 / 11 / 14 | 声光32字节 / 终局28字节 / 采集12字节 |
| 12 / 13 | 可靠事件32字节 / ACK8字节 |
| 15 / 16 | 事件诊断流32字节 / ACK8字节 |
| 18 | 成员接收槽配置报告32字节 |
| 19 / 20 | 启动身份挑战 / 应答24字节 |

细节字段以`network.c`、`network_score.h`、`event_transport.h`为准，不是可跨任意结构版本的公共互联网协议。所有C3同时升级。

## 可靠性与时序

每秒心跳；5秒无认证主机心跳或主机boot变化，成员暂停并需人工继续。首次/改变boot需HMAC认证挑战应答，24字节载荷含目标boot、本机boot、nonce16；本地待处理nonce在3秒内一次有效。旧boot命令、过期心跳和旧序号不能建立新身份。不是持久计数或全面抗回放协议，不宣称抵抗信任域内恶意密钥持有者。

主机命令type2载荷为内部`01/opcode/payload`后追加目标boot u32，总长6..20。相同事务重试保留seq与目标boot；成员只接受允许命令、已认证且近期心跳的主机。ACK8字节为原命令发送方（主机）boot u32、error i32，ACK帧boot为成员启动会话、seq对应请求。应用结果等待3秒、最多3次尝试；已执行同事务重放缓存结果，不重复执行。中途成员重启使事务失败，不能拿新启动ACK当旧执行结果。

整套配置按12字节分片、120秒有效期、FNV1a32完整校验，整体提交；比赛规则与飞手同步不覆盖每节点RF参数。部分失败不承诺原子全网回滚，主机报告节点错误，操作员确认后重试。

主机新场/继续：本机与成员预检、配置同步（新场）、时钟预算检查、定时准备/提交，运行中守护名单、session、state、boot和时钟。异常取消待开场并暂停可达节点；心跳携带取消边界补救丢包，不承诺消息丢失下原子同时开场。低误差时间样本10秒失效，按1000ppm老化；开场误差预算20ms，不能解读为实际测得精度。

## 成绩、身份与读取

type7为session u32@0,pilot u8@4,ownedMs u32@5,captures@9,laps@13,fastestMs@17。按最新同场快照替换，不重复相加；成员遥测要求相同boot与新鲜心跳。终场页带expected/included/missing，缺失结果不能当零分完整场次。结果身份使用本场冻结规则，详情见`result_record.h`、`match_verdict.h`。
