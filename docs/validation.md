# 验证范围

公开版本整理自2026-11-23开发基线。C3/C5已在ESP-IDF v6.0.2构建，双C5接同一C3的独立身份、配置状态与131个公开游戏页已读取并经开发客户端解析。这里不上传串口原始记录、设备标识和配置备份。

本仓库提供47套可移植C核心测试，涵盖六模式、八飞手、四槽模型、事件连续性、时钟映射、队列/丢包、主从身份/配置、定时开场、成绩/历史/终局、声光和寻机规则。它们是合成输入测试，不代表真实空口、射频、GPIO波形或安装设备完整验收。

尚待独立实物验证：手机BLE、真实RF计分与增益/门限精度、双接收器射频共存、实体声光/按钮、8成员并发与长时间负载、写中掉电及最终产品发布。公开源码可运行不等于以上全部通过。

计圈没有跨门门序赛制；八飞手不等于八路并行接收；数字频道表不等于数字解码；BLE Just Works不提供MITM保证；ESP-NOW HMAC不加密载荷，也不承诺持久全面抗回放。接口细节以本提交源码为准，不提供旧固件兼容层。

公开目录重新构建与发布核查：47/47套C核心测试已用TinyCC运行通过；公开源文件相对开发基线仅清理C3 main.c文件末尾空行。GitHub工作流另用gcc执行相同场景，不上传测试可执行文件或构建产物。
